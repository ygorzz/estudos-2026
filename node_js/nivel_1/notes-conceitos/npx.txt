O que é o npx? 

- npx (node package execute) -> Executor de pacotes do node integrado ao npm
- O npx é uma ferramenta que permite executar pacotes Node.js diretamente do terminal, utilizando uma versão instalada localmente no projeto, uma versão instalada globalmente ou, se necessário, baixando temporariamente o pacote sem instalá-lo globalmente na máquina.

Ex: npx create-react-app . 
    OBS: "." é o caminho onde quero criar a aplicação react. Nesse caso, na pasta atual.

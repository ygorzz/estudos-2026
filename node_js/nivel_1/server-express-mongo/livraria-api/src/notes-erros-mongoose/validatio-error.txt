2 - ValidationError: quando os dados não atendem os critérios definidos. EX: campos obrigatórios.
    -> possui uma prop errors que contém os erros ocorridos.
        -> o valor de cada erro é um obejto com a prop message
    Ex:
    {
        message: "Livro validation failed",
        errors: {
            titulo: {
            message: "O título é obrigatório"
            },
            autor: {
            message: "Autor inválido"
            }
        }
    }

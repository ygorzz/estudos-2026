Embedding X Rferenging

-> são modos de unir/referenciar dados de diferentes coleções

Embedding: 
-> dados que são consultados juntos devem ser armazenados juntos. 
-> Copia os dados de uma coleção para a outra -> não possui 'ligação viva'

Referencing:
-> referencia outras coleções por algum dado (PK, FK)

| 	  |               	**Embedding** (Incorporação)    |
|:---:|:------------------------------------------------|
| PRO | Dados retornados em uma única consulta        	|
| PRO | atualização e exclusão de dados em única operação|
| CON | duplicação de dados                           	|
| CON | documentos maiores                            	|
| 	  |              	**Referencing**              	|
| PRO | Não há duplicação de dados                    	|
| PRO | documentos menores                            	|
| CON | necessário "unir" dados de múltiplos documentos |
